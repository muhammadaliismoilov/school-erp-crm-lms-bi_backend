# Durbin-style backend continuation

This continuation adds backend modules that usually appear in a full school CRM/ERP/LMS platform but were not covered deeply in the previous archive.

## Added modules

### Documents
- Document templates
- Generated documents
- Sign requests
- Template variable replacement
- Contract/certificate/order/application document types

### Communication
- SMS/Telegram/Email/Push templates
- Campaigns
- Message deliveries
- Provider status tracking

### Transport
- Vehicles
- Routes
- Route stops
- Student transport assignments
- Daily transport trips

### Access Control
- Face terminals, turnstiles, cameras and card readers
- Face profiles
- Entry/exit access events
- Allowed/denied decisions

### Imports / Exports
- Import/export jobs
- Entity-based data jobs
- Row counters and error reports

### Workflow
- Approval requests
- Approver assignment
- Approve/reject/cancel decisions

`npm run build` passed after the continuation.

## Important note

This is still a backend implementation based on the supplied project architecture and Durbin-style school platform requirements. It is not a literal extraction of demo.durbin.uz source code.
